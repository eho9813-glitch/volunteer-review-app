# 志愿填报专家审核服务 MVP

这是根据 `志愿填报专家审核服务 PRD v1.1` 开发的静态 Web 应用原型，覆盖用户端、管理后台、高报师工作台三端闭环。

## 功能范围

- 用户端：上传志愿表、填写考生信息、邀请码抵扣、订单提交、报告查看、报告复制/打印、反馈、复核入口
- 管理后台：运营仪表盘、订单分配、邀请码生成、反馈管理、操作日志
- 高报师端：任务看板、审核面板、风险点管理、报告草稿、报告提交、资料不足流转

## 本地预览

直接打开 `index.html`，或使用任意静态服务器：

```bash
python -m http.server 4177
```

然后访问 `http://127.0.0.1:4177`。
